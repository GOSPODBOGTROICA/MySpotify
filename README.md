# 🎵 Custom Spotify Player Project

Проект собственного независимого музыкального плеера в стиле Spotify с поддержкой импорта плейлистов, плавного перехода (Crossfade 1-12 сек) и алгоритмического автовоспроизведения похожих треков.

---

## 🚀 Основные возможности

### 1. Точный дизайн и шрифты Spotify
* **Шрифты:** Оригинальное семейство `CircularSp-Cyrl` (Book, Bold, Black) и иконки `spoticon.ttf` из официального IPA.
* **Цветовая палитра:** Глубокий чёрный `#121212`, карточки `#181818`, фирменный акцент `#1DB954`.
* **Интерфейс:** Нижний мини-плеер, полноэкранный плеер с обложками, вкладки «Главная», «Поиск», «Медиатека», «Настройки».

### 2. Плавный переход (Crossfade 1–12 секунд)
* В настройках доступен ползунок: **от 1 до 12 секунд с шагом в 1 секунду**.
* За выбранное количество секунд текущий трек плавно затихает (`100% → 0%`), а следующий плавно нарастает (`0% → 100%`).
* Бесшовное сведение без пауз и тишины.

### 3. Автовоспроизведение похожих треков (Autoplay)
* Когда плейлист заканчивается, алгоритм анализирует исполнителей и стили из твоих треков и автоматически загружает бесконечную очередь похожей музыки, как Spotify Radio.

### 4. Высокое качество звука (High Quality Audio)
* Аудиопотоки передаются в формате **Opus 160 kbps** или **AAC 256 kbps**.
* В психоакустических тестах кодек Opus 160 kbps звучит чище, прозрачнее и детальнее, чем старый MP3 320 kbps.

### 5. Независимый стриминг без VPN
* Музыка воспроизводится через открытые европейские шлюзы (Piped/Invidious).
* Плеер не блокируется в РФ, не требует подписки Spotify Premium и не зависит от 14-дневных лимитов.

## 🛠 Сборка в IPA для iPhone

1. Проект загружается в репозиторий GitHub.
2. Вкладка **Actions** запускает `build_ios.yml` на виртуальном Mac.
3. Через 3 минуты в разделе Artifacts скачивается готовый файл **`CustomSpotify-iOS.ipa`**.
4. Файл устанавливается на iPhone через **Sideloadly** и работает без ограничений!
